# Projects

Portfolio projects by xMrShadyx — interactive tools, demos and experiments. All project interfaces and documentation are in English.

## Shady Build Forge

An interactive RPG character build calculator with side-by-side equipment and attribute comparisons.

- [Source and setup instructions](./shady-build-forge/README.md)
- [Hosted demo](https://shady-build-forge.daredevil91138.chatgpt.site) — currently owner-private.
- Features: two independent builds, playstyle presets, live damage and durability stats, browser-local saving and JSON export.

Equipment and combat formulas are illustrative and do not represent official Minecraft MMORPG balance.
