# Shady Build Forge

Interactive English RPG build calculator. Static HTML/CSS/JS; no installation required. Serve `dist` with any static HTTP server.

Includes two independent builds, three presets, four weapons and armor choices, bounded attribute allocation, live damage and durability comparison, local browser persistence and JSON export. Responsive keyboard-accessible controls.

All equipment and formulas are illustrative, not authoritative Minecraft MMORPG values. Formulas are documented in the interface. No connection to a live game, account or server. First portfolio prototype; real mod data can replace the isolated equipment arrays and calculate function.
